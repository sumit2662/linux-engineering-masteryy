# Zero-to-Advanced Roadmap

## Beginner
- [ ] Understand operating systems, Linux kernel, distributions, and open source.
- [ ] Install Linux in a virtual machine and use the terminal.
- [ ] Learn paths, files, directories, editors, help pages, and shell basics.
- [ ] Understand users, groups, ownership, and permissions.

## Intermediate
- [ ] Inspect and manage processes and services.
- [ ] Troubleshoot interfaces, IP addresses, routes, DNS, ports, and connectivity.
- [ ] Understand disks, partitions, filesystems, mounts, and backups.
- [ ] Write Bash scripts with validation, logging, and error handling.

## Security and engineering
- [ ] Apply safe host-hardening practices.
- [ ] Read authentication, service, and system logs.
- [ ] Understand Linux security tools and evidence integrity.
- [ ] Operate applications, containers, and CI runners.
- [ ] Build repeatable operational runbooks.

## Advanced
- [ ] Investigate resource pressure and performance.
- [ ] Understand kernel interfaces, namespaces, cgroups, and capabilities.
- [ ] Complete end-to-end projects with verification and rollback.
