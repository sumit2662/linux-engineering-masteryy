# Linux Glossary

- **Bash:** a widely used command-line shell and scripting language.
- **Bootloader:** software that loads the kernel and initial boot environment.
- **Cgroup:** mechanism for organizing and accounting for process resources.
- **Daemon:** background process that provides a service.
- **Distribution:** packaged operating system built around the Linux kernel.
- **Filesystem:** structures and rules used to store and retrieve data.
- **GID:** numeric group identifier.
- **Initramfs:** temporary initial root filesystem used during early boot.
- **Inode:** filesystem metadata object identifying a file.
- **Kernel:** core operating-system component managing hardware and resources.
- **Mount point:** directory where a filesystem is attached to the directory tree.
- **Namespace:** isolation mechanism that gives processes separate views of resources.
- **PID:** process identifier.
- **systemd:** system and service manager used by many distributions.
- **UID:** numeric user identifier.
- **VFS:** kernel abstraction for filesystem implementations.
